# Link Organizer 📚

링크를 체계적으로 관리하고 정리할 수 있는 모바일 앱입니다. 폴더와 태그를 활용해 웹 링크를 분류하고, 빠르게 검색하고 접근할 수 있습니다.

## 📱 주요 기능

### 1. 링크 관리

- **링크 추가**: URL을 입력하면 자동으로 제목과 썸네일을 가져옵니다
- **폴더 분류**: 링크를 폴더별로 정리할 수 있습니다
- **태그 시스템**: 여러 태그를 추가해 링크를 분류할 수 있습니다
- **메모 기능**: 각 링크에 메모를 추가할 수 있습니다
- **링크 열기**: 저장된 링크를 원클릭으로 브라우저에서 열 수 있습니다

### 2. 폴더 관리

- **폴더 생성**: 원하는 이름과 색상으로 폴더를 만들 수 있습니다
- **폴더 편집**: 폴더 이름과 색상을 변경할 수 있습니다
- **일괄 관리**: 여러 폴더를 선택해 한 번에 삭제할 수 있습니다
- **폴더 검색**: 폴더 이름으로 빠르게 검색할 수 있습니다

### 3. 검색 기능

- **통합 검색**: 링크, 폴더, 태그를 한 번에 검색할 수 있습니다
- **필터링**: 전체/링크/폴더/태그별로 검색 결과를 필터링할 수 있습니다
- **실시간 검색**: 입력하는 즉시 검색 결과가 표시됩니다

### 4. 사용자 경험

- **직관적인 UI**: 깔끔하고 모던한 디자인
- **빠른 접근**: 하단 네비게이션으로 주요 화면에 빠르게 접근
- **애니메이션**: 부드러운 전환 애니메이션으로 사용자 경험 향상

## 🚀 시작하기

### 필수 요구사항

- Node.js 18 이상
- npm 또는 yarn
- Expo CLI (전역 설치 권장)

### 설치 및 실행

1. **의존성 설치**

   ```bash
   npm install
   ```

2. **개발 서버 시작**

   ```bash
   npm start
   # 또는
   npx expo start
   ```

3. **플랫폼별 실행**
   - **iOS 시뮬레이터**: `npm run ios` 또는 `i` 키 입력
   - **Android 에뮬레이터**: `npm run android` 또는 `a` 키 입력
   - **웹 브라우저**: `npm run web` 또는 `w` 키 입력
   - **Expo Go 앱**: QR 코드 스캔 (모바일 기기 필요)

## 📖 사용자 가이드

### 홈 화면

앱을 실행하면 홈 화면이 표시됩니다.

**주요 기능:**

- **폴더 섹션**: 최근 사용한 폴더들이 가로 스크롤로 표시됩니다
  - 폴더를 탭하면 해당 폴더의 링크 목록을 볼 수 있습니다
  - "전체 보기" 버튼을 눌러 모든 폴더를 관리할 수 있습니다
- **최근 링크 섹션**: 최근에 저장한 링크들이 표시됩니다
  - 링크를 탭하면 상세 정보를 볼 수 있습니다
- **플로팅 버튼**: 우측 하단의 `+` 버튼을 눌러 새 링크를 추가할 수 있습니다

**하단 네비게이션:**

- **홈**: 홈 화면으로 이동
- **검색**: 검색 화면으로 이동
- **설정**: 설정 화면으로 이동

---

### 링크 추가하기

1. **링크 추가 화면 열기**

   - 홈 화면의 플로팅 버튼(`+`) 클릭
   - 또는 폴더 상세 화면의 플로팅 버튼 클릭 (해당 폴더에 바로 추가)

2. **URL 입력**

   - 상단의 URL 입력 필드에 링크 주소를 입력하거나 붙여넣기
   - URL을 입력하면 자동으로 제목과 썸네일이 로드됩니다

3. **폴더 선택** (선택사항)

   - "폴더 선택" 섹션에서 링크를 저장할 폴더를 선택합니다
   - 최근 3개 폴더가 버튼으로 표시되며, "더보기"를 눌러 전체 폴더 목록을 볼 수 있습니다
   - "+ 새 폴더 만들기"를 눌러 바로 새 폴더를 만들 수 있습니다

4. **태그 추가** (선택사항)

   - "태그 추가" 섹션에서 태그를 입력하고 엔터를 누르면 추가됩니다
   - 추가된 태그는 `#태그명` 형식으로 표시되며, X 버튼을 눌러 제거할 수 있습니다

5. **저장**
   - 하단의 "링크 저장하기" 버튼을 눌러 저장합니다
   - 저장 후 자동으로 이전 화면으로 돌아갑니다

**팁:**

- 폴더 상세 화면에서 링크를 추가하면 해당 폴더가 자동으로 선택됩니다
- URL만 입력해도 저장할 수 있으며, 나중에 폴더나 태그를 추가할 수 있습니다

---

### 링크 검색하기

1. **검색 화면 열기**

   - 하단 네비게이션의 "검색" 탭 클릭
   - 또는 홈 화면 헤더의 검색 아이콘 클릭

2. **검색어 입력**

   - 상단 검색창에 검색어를 입력합니다
   - 입력하는 즉시 검색 결과가 표시됩니다

3. **필터 선택** (선택사항)

   - 검색창 아래의 필터 바에서 검색 범위를 선택할 수 있습니다:
     - **전체**: 링크, 폴더, 태그 모두 검색
     - **링크**: 링크 제목과 URL만 검색
     - **폴더**: 폴더 이름만 검색
     - **태그**: 태그 이름만 검색

4. **결과 확인**

   - **폴더 결과**: 검색된 폴더들이 가로 스크롤 카드로 표시됩니다
   - **링크 결과**: 검색된 링크들이 리스트로 표시되며, 썸네일과 폴더 정보가 함께 표시됩니다

5. **링크 열기**
   - 검색 결과에서 링크를 탭하면 상세 화면으로 이동합니다
   - 폴더를 탭하면 해당 폴더의 링크 목록으로 이동합니다

**팁:**

- 검색어를 지우면 검색 결과가 사라집니다
- 검색 결과가 없으면 "검색 결과가 없습니다" 메시지가 표시됩니다

---

### 링크 상세 보기

링크를 탭하면 상세 화면이 표시됩니다.

**표시되는 정보:**

- **썸네일 이미지**: 링크의 대표 이미지 (있는 경우)
- **제목**: 링크의 제목
- **도메인**: 링크의 도메인 주소 (밑줄 표시, 탭하면 링크 열기)
- **폴더**: 링크가 속한 폴더 (있는 경우)
- **태그**: 링크에 추가된 태그들 (있는 경우)
- **메모**: 링크에 추가된 메모 (있는 경우)
- **저장 날짜**: 링크를 저장한 날짜

**주요 기능:**

- **링크 열기**: 하단의 "링크 열기" 버튼을 눌러 브라우저에서 링크를 엽니다
- **편집**: 우측 하단의 편집 버튼을 눌러 링크 정보를 수정합니다
- **뒤로가기**: 상단 좌측의 뒤로가기 버튼을 눌러 이전 화면으로 돌아갑니다

---

### 폴더 관리하기

#### 폴더 목록 보기

1. **폴더 목록 화면 열기**

   - 홈 화면의 폴더 섹션에서 "전체 보기" 클릭
   - 또는 링크 추가 화면에서 "더보기" 클릭

2. **폴더 검색**

   - 상단 검색창에 폴더 이름을 입력하면 실시간으로 필터링됩니다

3. **폴더 열기**
   - 폴더를 탭하면 해당 폴더의 링크 목록으로 이동합니다

#### 폴더 추가하기

1. **폴더 추가 모달 열기**

   - 폴더 목록 화면 우측 상단의 `+` 버튼 클릭

2. **폴더 정보 입력**

   - 폴더 이름 입력
   - 색상 선택 (기본값: 파란색)

3. **저장**
   - "저장" 버튼을 눌러 폴더를 생성합니다

#### 폴더 편집 모드

폴더를 길게 누르면 편집 모드로 진입합니다.

**편집 모드 기능:**

- **체크박스 선택**: 여러 폴더를 선택할 수 있습니다
- **일괄 삭제**: 선택된 폴더들을 한 번에 삭제할 수 있습니다
- **개별 편집**: 각 폴더의 연필 아이콘을 눌러 이름과 색상을 수정할 수 있습니다
- **개별 삭제**: 각 폴더의 휴지통 아이콘을 눌러 삭제할 수 있습니다

**편집 모드 종료:**

- 헤더의 "취소" 버튼을 눌러 편집 모드를 종료합니다
- 뒤로가기 버튼을 눌러도 편집 모드가 종료됩니다

**폴더 수정 팝업:**

- 연필 아이콘을 누르면 폴더 수정 팝업이 표시됩니다
- 이름과 색상을 변경한 후 "저장"을 누르면 변경사항이 적용됩니다
- 팝업을 닫아도 편집 모드는 유지되므로 여러 폴더를 연속으로 수정할 수 있습니다

**주의사항:**

- 링크가 있는 폴더를 삭제하려고 하면 확인 메시지가 표시됩니다
- 폴더를 삭제해도 폴더 안의 링크는 삭제되지 않습니다 (링크는 폴더 없이 저장됩니다)

---

### 폴더 상세 보기

폴더를 탭하면 해당 폴더의 링크 목록이 표시됩니다.

**주요 기능:**

- **통계 카드**: 폴더 내 링크 개수와 참여자 수를 표시합니다
- **정렬 옵션**: "최신순" 드롭다운으로 링크 정렬 방식을 선택할 수 있습니다
- **링크 목록**: 폴더에 속한 링크들이 카드 형태로 표시됩니다
  - 각 링크 카드에는 썸네일, 제목, 도메인, 메모(있는 경우)가 표시됩니다
  - 링크를 탭하면 상세 화면으로 이동합니다
  - 더보기 버튼(⋮)을 눌러 링크를 삭제할 수 있습니다
- **링크 추가**: 플로팅 버튼(`+`)을 눌러 해당 폴더에 바로 링크를 추가할 수 있습니다

---

### 설정

하단 네비게이션의 "설정" 탭을 눌러 설정 화면으로 이동합니다.

**주요 설정 항목:**

1. **프로필 섹션**

   - 프로필 이미지, 이름, 이메일이 표시됩니다
   - 프로필 이미지 우측 하단의 편집 배지를 눌러 프로필을 수정할 수 있습니다

2. **계정**

   - 프로필 편집: 프로필 정보를 수정합니다
   - 비밀번호 변경: 계정 비밀번호를 변경합니다

3. **앱 설정**

   - 알림 설정: 앱 알림을 관리합니다
   - 다크 모드: 다크 모드를 켜거나 끕니다 (토글 스위치)

4. **데이터**

   - 링크 내보내기: 저장된 링크를 내보냅니다
   - 캐시 삭제: 앱 캐시를 삭제합니다 (사용량 표시)

5. **지원**
   - 고객센터: 고객 지원에 문의합니다
   - 개인정보 처리방침: 개인정보 처리방침을 확인합니다
   - 로그아웃: 계정에서 로그아웃합니다 (빨간색 강조)

**버전 정보:**

- 화면 하단에 현재 앱 버전이 표시됩니다

## 🎯 주요 사용 시나리오

### 시나리오 1: 새 링크 저장하기

1. 인터넷에서 흥미로운 글을 발견했습니다
2. 링크를 복사하고 앱을 엽니다
3. 홈 화면의 `+` 버튼을 누릅니다
4. URL을 붙여넣고, 적절한 폴더를 선택합니다
5. 관련 태그를 추가합니다 (예: `#개발`, `#튜토리얼`)
6. 필요하면 메모를 추가합니다
7. "링크 저장하기"를 눌러 저장합니다

### 시나리오 2: 저장한 링크 찾기

1. 검색 화면으로 이동합니다
2. 기억나는 키워드를 입력합니다 (예: "React")
3. 검색 결과에서 원하는 링크를 찾습니다
4. 링크를 탭해 상세 정보를 확인합니다
5. "링크 열기" 버튼을 눌러 브라우저에서 엽니다

### 시나리오 3: 폴더 정리하기

1. 폴더 목록 화면으로 이동합니다
2. 정리할 폴더를 길게 누릅니다
3. 편집 모드에서 여러 폴더를 선택합니다
4. 불필요한 폴더들을 삭제합니다
5. 이름을 변경하고 싶은 폴더의 연필 아이콘을 누릅니다
6. 새 이름을 입력하고 저장합니다

### 시나리오 4: 특정 주제의 링크 모아보기

1. 홈 화면에서 관련 폴더를 탭합니다
2. 폴더 상세 화면에서 해당 주제의 모든 링크를 확인합니다
3. 필요하면 정렬 옵션을 변경합니다
4. 링크를 탭해 상세 정보를 확인하거나 바로 열 수 있습니다

## 🔧 개발 가이드

### 프로젝트 초기화

처음 프로젝트를 클론한 경우:

```bash
npm install
npm start
```

### 코드 스타일

- ESLint를 사용해 코드 스타일을 검사합니다
- `npm run lint`로 린트 검사를 실행할 수 있습니다

### 데이터 초기화

프로젝트를 초기 상태로 되돌리려면:

```bash
npm run reset-project
```

---

## 📝 주요 기능 상세

### 링크 메타데이터 자동 수집

URL을 입력하면 자동으로 다음 정보를 가져옵니다:

- 페이지 제목
- 썸네일 이미지
- 링크 타입 (YouTube, Twitter, 일반 웹사이트 등)

### 검색 알고리즘

검색은 다음 항목을 대상으로 수행됩니다:

- 링크 제목
- 링크 URL
- 폴더 이름
- 태그 이름

대소문자를 구분하지 않으며, 부분 일치 검색을 지원합니다.

### 데이터 저장

모든 데이터는 기기의 로컬 저장소(AsyncStorage)에 저장됩니다:

- 인터넷 연결 없이도 사용 가능
- 빠른 데이터 접근
- 개인정보 보호

## 🐛 문제 해결

### 앱이 시작되지 않을 때

1. `node_modules` 폴더 삭제 후 재설치:

   ```bash
   rm -rf node_modules
   npm install
   ```

2. Expo 캐시 클리어:
   ```bash
   npx expo start --clear
   ```

### 데이터가 표시되지 않을 때

- 앱을 완전히 종료한 후 다시 실행해보세요
- 개발 모드에서는 데이터가 초기화될 수 있습니다

### 검색이 작동하지 않을 때

- 검색어를 지우고 다시 입력해보세요
- 필터 옵션을 확인해보세요
